# Projet Bibliothèque Numérique

## Auteur
Beverly St Come

## Description
Application Java permettant de gérer une bibliothèque numérique.

## Fonctionnalités
- Lecture d'un fichier CSV contenant les documents
- Gestion des documents (livres, magazines, ebooks)
- Gestion des emprunts et des retours
- Validation des données
- Exceptions personnalisées
- Statistiques sur les documents
- Génération d'un rapport TXT

## Concepts Java utilisés
- Héritage
- Classe abstraite
- Interfaces
- ArrayList
- Exceptions personnalisées
- Lecture et écriture de fichiers

## Exécution
1. Ouvrir le projet dans IntelliJ IDEA.
2. Exécuter la classe `Main.java`.
3. Utiliser le menu affiché dans la console.

## Structure du projet
- `src/model` : classes métier
- `src/interfaces` : interfaces
- `src/exceptions` : exceptions personnalisées
- `src/services` : services et traitement des données
- `data` : fichiers CSV
